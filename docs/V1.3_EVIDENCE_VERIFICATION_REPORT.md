## Known Limitations

1. **Full data replay not implemented**: EvidenceTrail is audit-reproducible, not fully replayable. Provider data changes between runs.
2. **Per-cell exclusion detail not available**: Exclusion ledger records batch-level counts (e.g. "5 cells removed by railway"), not per-cell IDs.
3. **Constraint enforcement evidence minimal**: `ConstraintEvidence` schema deferred to v1.3.1; current version shows constraint checks from `locations.exclusions`.
4. **`openai`-dependent tests**: `test_jobs_imports_evidence_builder` and `test_build_methodology_contains_layers` skip in local env without `openai` installed. Run `pip install openai` to include them.
5. **Evidence trail absent from demo/saved results**: Demo scenarios and saved analyses loaded from Firestore don't include `evidenceTrail`. UI shows "unavailable" gracefully.
