# v1.3.0 Evidence Schema Reference

**evidenceVersion:** `"1.3.0"`
**Location:** `backend-py/app/models/evidence.py`

## EvidenceTrail (root)

| Field | Type | Description |
|---|---|---|
| `evidenceVersion` | `str` | Always `"1.3.0"` |
| `analysisId` | `str` | `"analysis_" + jobId[:8]` |
| `jobId` | `str` | Full UUID job ID |
| `createdAt` | `str` | ISO-8601 UTC timestamp |
| `appVersion` | `str` | Backend app version (e.g. `"1.3.0"`) |
| `engineVersion` | `str` | Scoring engine version |
| `prompt` | `PromptEvidence` | Original prompt + planning metadata |
| `dataSnapshot` | `DataSnapshotEvidence` | Provider mode + snapshot ID |
| `studyArea` | `StudyAreaEvidence` | Polygon hash + H3 cell counts |
| `providerQueries` | `ProviderQueryEvidence[]` | Per-query evidence (no secrets) |
| `factors` | `FactorEvidence[]` | Per-factor schema + candidate scores |
| `candidates` | `CandidateEvidence[]` | Per-candidate breakdown |
| `exclusions` | `ExclusionEvidence[]` | H3-cell + candidate exclusion ledger |
| `scoring` | `ScoringEvidence` | Formula, weights, normalization |
| `recommendationSummary` | `RecommendationSummaryEvidence` | Count summary |
| `limitations` | `str[]` | Honest list of data/reproducibility limitations |

## ProviderQueryEvidence

```json
{
  "provider": "OSM Overpass" | "Google Places" | "ORS" | "Internal" | "Derived",
  "queryPurpose": "main_layer_fetch",
  "queryType": "union_tag_query",
  "queryParamsPublic": { "tagCount": 5, "tagSample": ["amenity=cafe", ...], "bboxApprox": {...} },
  "secretFieldsRedacted": true,
  "requestedAt": "2026-06-25T10:00:00Z",
  "responseStatus": "ok" | "partial" | "error",
  "featureCount": 42,
  "warning": null
}
```

**Rules:**
- `secretFieldsRedacted` is always `true`
- `queryParamsPublic` never contains API keys, authorization, or tokens
- Any key matching `api_key|authorization|token|secret|password` is replaced with `"[REDACTED]"`

## Security

`EvidenceTrail.safe_dict()` runs `_scrub_secrets()` recursively before serialization. Any dict key matching `api_key|apikey|authorization|token|secret|password|openai_api_key|...` is replaced with `"[REDACTED]"`. Raw provider responses are never stored — only query metadata and feature counts.

## Reproducibility Classification

| Level | What it means | Supported in v1.3.0? |
|---|---|---|
| **Deterministic planning** | Same prompt → same factor schema + weights | ✅ Yes (v1.2.0) |
| **Audit reproducible** | Can verify what data was queried + how scores were computed | ✅ Yes (v1.3.0) |
| **Full data replay** | Re-run with identical OSM/Places snapshot → identical candidates | ❌ Not yet |

Label used in limitations: `"Audit reproducible — the plan and scoring formula are stable. Full data replay requires cached provider snapshots."`
